A dark terminal theme, packaged to reuse

Everything on this page is styled by terminal-theme.css alone - the portal's own stylesheet is not loaded here (the portal follows this theme, not the other way round). A test keeps the template's design tokens in sync, so this file is always the current look.

use it

download terminal-theme.css

Or fetch the newest copy any time from {{ request.url.scheme }}://{{ request.url.netloc }}/static/terminal-theme.css. Start a page from this skeleton:

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My thing</title>
  <link href="https://fonts.googleapis.com/css2?family=Fira+Code:wght@400;500;600;700&display=swap" rel="stylesheet">
  <link rel="stylesheet" href="terminal-theme.css">
</head>
<body>
  <div class="screen">
    <div class="terminal-window">
      <div class="terminal-header">
        <div class="window-controls">
          <span class="window-dot close"></span>
          <span class="window-dot minimize"></span>
          <span class="window-dot maximize"></span>
        </div>
        <a class="wordmark" href="/">MY THING</a>
        <div class="window-stats"><span>{{ SITE.handle }}</span></div>
      </div>
      <div class="terminal-body">
        <h1>Hello</h1>
        <h2>a section</h2>
        <p>Content here.</p>
        <div class="terminal-footer">
          <span>my thing</span><span class="cursor">&nbsp;</span>
        </div>
      </div>
    </div>
  </div>
</body>
</html>
